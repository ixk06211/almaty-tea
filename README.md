# 阿拉木图高端奶茶店 · 选址调研包

给准备在阿拉木图（Алматы）开高端现制茶饮店的团队使用。包含一份可以拿在手机上直接上街用的调研工具，以及一套从定位到开业的整体规划。

## 包含什么

| 文件 | 内容 |
|---|---|
| `index.html` | 封面页，入口 |
| `toolkit.html` | 互动调研工具：人流计数器与计时器、点位评分卡、租金红线检查、单店盈利测算、四份现场检查清单、俄语问句模板。可离线使用，数据只存在使用者本机 |
| `plan.md` | 整体落地规划：市场判断、点位类型取舍、人流实测方法、合规与税务要点、供应链、产品本地化、定价模型、时间表、风险对策、待核实清单 |

## 怎么用

1. 打开站点首页，进入「实地调研工具包」。
2. 手机上建议「添加到主屏幕」，之后可离线打开。
3. 每个候选点位都新建一份记录：先测人流，再打分，最后算盈利模型。
4. 结论只有三种：做 / 条件性做（先谈租金）/ 换点位。

## 三个必须记住的判断线

- 街铺高峰小时**有效人流**低于 150 人基本不做（有效人流 = 经过门口约 5 米、看起来 15–40 岁的行人）。
- 租金占预估营业额**超过 20% 直接放弃**，10–15% 才是健康区间。
- 回本周期目标 **18 个月以内**，超过 24 个月风险偏高。

## 说明

文中所有关于当地租金、税率、薪资、竞品、许可的具体数字，都属于需要用现场一手信息核实的参数，工具包里给的只是行业基准与判断框架，不能替代实地尽调。
